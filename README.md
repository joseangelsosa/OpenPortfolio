# OpenPortfolio

OpenPortfolio es una prueba de concepto open-source para monitorizar una cartera de inversión a largo plazo.

La arquitectura prevista utilizará Python para la lógica principal, yfinance como proveedor inicial de datos de mercado, GitHub Actions para la automatización, Telegram para el envío de alertas y, posteriormente, Streamlit para la presentación interactiva.

El proyecto priorizará servicios gratuitos siempre que sea viable. Su finalidad es informativa y de seguimiento: no proporcionará recomendaciones automáticas de compra o venta ni ejecutará operaciones de trading.

## Estado del proyecto

OpenPortfolio se encuentra en la fase inicial de arquitectura.
